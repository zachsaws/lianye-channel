# 渠道接洽判断研究原型

本原型先建立规则基线和共同输入。尚未进行独立AI对照，不提供准确率或效率结论。

## 共同任务

输入同一份产品资料和渠道证据，输出：值得进一步核实的对象、不能确定的条件、暂缓原因、条件变化影响。不能输出“已匹配成功”、预期销量或采购意愿。

## 判断口径

- 产品方向相关，仅获得继续研究资格，不获得采购适配结论。
- 产品没有可用演示、服务责任或履约安排时，先补产品资料。
- 经营者准入条件、采购权和商业条件未核实，不能建议投入铺货。
- 软件产品需要独立的实施与持续服务责任，不能仅依据硬件经销目录判断。
- 硬条件变化重新检查；旧结论保留版本，不覆盖历史。

## AI对照要求

使用 `cases.json` 和当前渠道证据，禁止额外补入未引用事实。先冻结规则输出，再保存AI原始输入、输出、模型与运行日期。人工逐条检查出处、遗漏、推断及可执行下一步。不能将人工写出的理想答案冒充AI运行结果。

评审重点包括：是否错误推断采购意愿，是否把机构软件推荐到普通零售，是否发现演示缺失，是否在服务条件变化后撤销旧判断，是否提出有针对性的核实问题。

## 下一次实验需要

扩大到六个方向的经营证据；补充明确的正反例；用真实模型运行相同证据下的对照。当前规则只能做准备度和方向筛查，不能证明跨项目经验复用。
