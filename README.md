### 好产品，不该输在渠道上。

**为 AI 产品打开销售通路，让下一款新品用上整张网络的经验。**

AI 正在让更多产品成为可能：新的硬件、新的交互，也有新的软件服务。产品不断变化，进入市场却仍要逐家寻找渠道、解释价值、谈合作条件，从头积累销售经验。

联野探索的是这一环节的变化：把分散的渠道知识、合作过程与经营反馈连接起来，让新品更快找到值得进入的销售通路，让渠道更容易判断一款陌生产品是否值得经营。

[查看公开官网](https://lianye-channel.zachsaw.chatgpt.site/) · [阅读研究资料](research/README.md) · [浏览渠道目录](research/channels/channel-directory.csv)

## 我们在做什么

**打开通路。** 从全国分销、区域专业零售到内容电商与场景采购，研究具体经营者、对应买家与进入条件。渠道网络的价值，来自相关性与专业深度。

**推进生意。** 连接品牌与渠道，围绕选品、合作条件、样品体验、首批开卖及后续扩展推进合作。品牌专注产品，渠道获得值得认真讨论的新业务。

**积累可复用的经验。** 一次合作留下的条件、疑问与结果，可能帮助下一款新品少走弯路。AI 的研究重点是比较这些非标准、持续变化的信息，找到相关先例，同时看清产品、价格、客群和服务要求的差异。

## 为什么值得继续研究

名单让人知道可以找谁，经营经验让人知道为什么值得谈、还差什么，以及下一步怎么做。真正的机会在于：一个项目留下的信息，能否在可靠且获授权的前提下，帮助整个网络做出更好的判断。

这也是项目需要检验的核心命题。AI 经验网络仍在建设；仓库没有将公开市场主体写成已签约合作，没有虚构客户案例、销售结果或已实现的 AI 能力。

## 本地查看

无需安装依赖或构建，在仓库目录运行：

```sh
python3 -m http.server 8000 --directory site
```

打开 http://localhost:8000 即可。主要页面为 `site/index.html`。

## 继续迭代

内容面向 AI 产品创业者、渠道经营者与投资人。文案应简短具体，视觉保持彩色、具象、统一；每个模块说明不同的事。当前渠道研究聚焦中国市场，海外通路留待后续版本。

修改后检查完整页面、动效播放、渠道筛选、键盘操作、移动端和联系入口。仓库为私有，官网公开；提交代码不会自动覆盖线上网站。正式发布需获得项目负责人的授权。
