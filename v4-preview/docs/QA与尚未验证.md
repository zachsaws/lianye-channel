# QA、自审与尚未验证

## 实际执行
在真实浏览器中打开本机V4预览，检查桌面1440×900和手机390×844。两宽度下覆盖三条路径的三个事件、三类产品的三个步骤、合作六步。另检查320、768、1024宽度，未发现主体页面横向溢出。见qa/state-checks.json和responsive-motion.json。

资料搜索“量子位”得到一条对应参考，来源链接与关系边界可见；原生dialog打开、Escape关闭及焦点返回实测通过。重置后240条资料与26个细类恢复。见catalog-checks.json。

手机导航打开/Escape关闭实测通过。手机合作步骤原有品牌卡遮挡纸张内容，已改为上下分层；六步文字区域与品牌卡重新检查无交叉遮挡，见mobile-repairs.json，并人工查看修复后截图。

首屏以WebGL实际运行，已采到三个自动阶段以及持续增长的渲染帧计数。qa/hero-motion.mp4是实际浏览器截图序列按真实采样间隔编码，不是设计效果视频；成片17.16秒，采样时长17.182秒。见motion-times.json。

减少动态时默认暂停，三维产品保持显示；手动选体验阶段有效，主动播放恢复本页动态。静态截图多在减少动态偏好下选取明确状态保存，正常自动播放由录像单独证明。

初验修复了首次requestAnimationFrame时间戳可能早于初始化时间造成的负时间索引；后续录屏期间未出现新增控制台错误或警告，见runtime-errors.json。三维在暂停后改变窗口尺寸会标记重绘，不因resize清空画布。

## 素材与可读性
四幅新生成的原创场景，已逐幅查看并放入项目assets。产品、相机、桌台、手部沿用同一色彩与材质；不将生成画面称为真实合作现场。所有最终截图中的图片均已加载。

桌面、手机逐模块截图和全站截图在qa；人工检查了首屏、销售路径、软件示意、图谱、合作、双边价值与联系。最终手机合作文字遮挡修复已重新截图。设计稿用于构图指导，三维实现与栅格探索的材质细节并非像素级一致；不宣称完全还原Clay完成度或已获用户审美认可。

## 无障碍与性能边界
保留主内容跳转、语义标题、图片替代文字、焦点样式、键盘分组左右/Home/End切换、原生dialog和Escape关闭；主要状态不只靠颜色。3D对象有等价文本与按钮操作，不依赖只能点中的三维坐标。

本机一次加载记录DOMContentLoaded约120ms、load约139ms，12个资源全部同源。只代表本机环境，不能当公网性能成绩。运行时没有在线字体、外部图片或CDN脚本依赖。三维使用低功耗倾向、像素比上限1.5、约30fps渲染上限及离屏停绘。

未完成真实手机硬件、多浏览器、完整屏幕阅读器或公网Lighthouse验收；没有无障碍认证或性能排名。内嵌浏览器截图接口对模拟尺寸有裁切问题，最终文件采用Chrome开发协议按1440/390的明确尺寸保存。
