2026-10-23。源代码维护于 v4-preview/，原生产 site/、site-preview/ 等目录没有改动。品牌名尚未选定，保留联野及「好产品，不该输在渠道上。」；未把「AI时代的新产品分发网络」作为首页副标题。

## 对标结论

本轮对照当前官方网站，而不以未经核实的 ARR、热度或榜单排序：

| 参考 | 观察到的做法 | 本站落实 |
| --- | --- | --- |
| [Clay](https://www.clay.com/) | 统一材质与视觉隐喻贯穿首页，能力旁有具体用途与成果 | 保留开放展台与纸张语言，加入真实材质的原创产品场景；三维触碰响应与品牌承接继续可操作 |
| [Lindy](https://www.lindy.ai/) | 把具体任务、动作与结果放在一起展示 | 三条路径分别呈现拍摄、软件任务、门店上手，再进入买家问题与品牌承接 |
| [Gumloop](https://www.gumloop.com/) | 工作语境与演示、使用入口衔接 | 合作模块可查看渠道建议、执行安排与反馈判断，最后进入实际邮箱沟通 |

Clay 在 Chrome 中进行了实际视觉查看；Lindy、Gumloop 读取当前首页结构与内容。没有把客户成绩、客户标志或别人的艺术素材移植到本站。Relay 当前官网已宣布2026年9月停止服务，未当作当前活跃对标。

本轮达到的是一份完整、可交互、经过实际浏览检查的官网交付。统一性、业务可读性与交互完整度有具体落实；不以自评分数宣称审美已经胜过参考站。成熟公司拥有的真实客户证明、产品积累与合作成果，需要业务实际产生。

## 完成内容

1. 首页直接说明服务对象、渠道与购买，保留传播口号。
2. 内容路径改为口袋相机实际拍摄；门店路径为与首屏一致的陪伴设备上手。两张场景图为原创生成的概念画面。
3. 软件路径为前端制作的试用任务演示，素材、剪辑时间线、结果判断和购买问题随场景推进；不调用AI生成接口，不伪装成已经上线的产品。
4. 九个代表性经营者分别整理业务事实、人群、匹配判断、建议切入点及待沟通条件。匹配判断是联野建议，不冒充对方已经接受合作。
5. 保留原240条经营者资料与26个二级经营分类。九个代表项核对官方页面；其余保留原研究日期及来源，未声称全量实时复核。
6. 合作模块展示可切换、可下载的三个交付示例，品牌直接承接成交、履约与售后。
7. 手机切换交付后滚动到示例，减少点后看不到变化的问题；补充复制邮箱与第一次沟通说明。

## 实际浏览验收

浏览器专用连接返回 transport closed，改用独立 Chrome 窗口完成真实页面、设备仿真和交互检查。未以静态代码检查代替浏览。

| 检查 | 结果与证据 |
| --- | --- |
| 桌面1440×900 | document scrollWidth=1440，未横向溢出；WebGL正常；三路径、交付切换与目录可用。见 desktop-qa.json |
| 手机390×844 | scrollWidth=390，未横向溢出；独立纵向构图；菜单打开、跳转、关闭通过。见 mobile-qa.json |
| 320、768、1024稳定视口 | 记录中 scrollWidth 等于视口宽度；控制尺寸过程中出现的临时无效宽度不作为有效断点结果 |
| 目录 | 全部方向返回240条；搜索量子位返回1条；重置与收起可用 |
| 详情与键盘 | 智玩店、站酷显示独立事实和建议；站酷弹窗 Escape 关闭后焦点回到原按钮 |
| 复制 | 实际点击后显示邮箱已复制、沟通提纲已复制；没有假提交表单 |
| 动效 | 真实三维展台渲染；场景阶段变化有浏览记录；暂停生效；模拟 prefers-reduced-motion 后 paused=true；显式播放后 reduce=true、paused=false。完成后取消模拟 |
| 手机交付定位 | 切换执行安排后交付纸张顶部进入可见范围；事件记录 paperTop=162，包含页面滚动留白 |
| 图片与脚本 | 浏览器记录无缺失图片，交互期间未捕获页面异常；控制台有浏览器扩展的 unload 策略告警，来源为 chrome-extension，并非本站脚本 |
| 静态检查 | HTML 标签平衡、ID唯一、引用资源存在；四个脚本语法检查通过；原生产目录无差异 |
| 性能范围 | 有本地加载记录（示例 load 722ms），不能替代线上弱网、真实手机或正式 Lighthouse 性能认证 |
