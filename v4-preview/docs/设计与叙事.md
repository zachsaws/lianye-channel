# 设计规范与叙事

## 已选方向
新品登场。以大尺度、可触摸的产品展台代替微缩街区。核心问题是：读者能否看懂新品进入真实需求场景时，需要怎样的介绍、体验和品牌承接。

A与B两套原创高保真探索分别保存在design/direction-a.png和direction-b.png。选择A的材料与构图；B的巨大单一产品容易把联野误读成工业设计或硬件品牌，且其探索图的业务分类不符合既定路径。具体见direction-review.md。

## 颜色、排版、构图
暖白#f6f1e8与墨色#202722作为阅读基础。钴蓝#315bdf、橙色#ef5a35、薰衣草色#d8cff3、奶油黄#f4d66c构成统一展台材料；多个色相来自用户对彩色具象的要求，不套用单强调色的通用模板。

中文独立定标，使用本机中文无衬线字体。桌面主标题约80px、手机38px，按语义断行；无衬线字体本身不等于低质，不把英文字距和行距作为中文的必然标准。正文桌面15–18px，手机13–15px；主要操作同时用文字、下划线或箭头表达状态。资料图注为较小字号，可通过浏览器缩放阅读。

首屏为统一画布，生成静帧用于不支持WebGL时的完整降级；正常首屏为原创实时三维。手机不是缩放桌面：独立镜头范围、文字/场景分层、上下布局、合作纸张与品牌卡分开、分类索引横向浏览。

## 商业叙事
1. 好产品不该输在渠道上：从被看见到体验，再到品牌承接。
2. 一款新品三种相遇：内容、社群、门店，分别对应不同购买前疑问。合作形式独立可见，可跨路径组合。
3. 买家问的不只是参数：软件用自己的素材跑流程，陪伴设备看互动与限制，创作硬件看原始效果与兼容条件。
4. 深入公开资料：从经营角色和26个细类探索240个市场参考，逐条有来源，不作合作或销量证明。
5. 一次合作有人承接：从产品事实、介绍提纲、责任约定到实际体验、品牌答疑与结果复盘。输出是沟通依据，不是必然成交的自动流水线。
6. 双边价值与联系：给品牌明确拟交付，给伙伴明确支持与责任，真实邮件与沟通提纲收口。

## 动态与边界
首屏三个阶段约14.1秒循环。体验阶段手部进入、按钮发生位移、样机出现预设响应；最后纸张变为品牌承接事项。三维对象使用Three.js本地依赖和原创几何，没有复制Clay资产。这里的样机反馈完全预设，不代表实际产品具有该能力。

内容路径有对焦、快门与记录；门店有触点响应；社群有试用任务进度。路径背景人物和手部是静态生成渲染，不宣称全部人物已动画化。软件时间线只示意步骤，不运行AI。合作纸张逐步改变内容，避免把货物流转当商业本质。

自动播放可全局或逐模块暂停，手动选步骤暂停对应模块的自动推进。模块离开视口、页面隐藏停止推进；三维只在需要时渲染。减少动态时保留产品和完整状态，可手动查看步骤；主动播放可以覆盖当前页面的减少动态设置。
