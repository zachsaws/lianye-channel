# V4.2 页面结构与验收

更新：2026-10-23。本轮执行用户确认的信息清理方向，保留 V4 的配色、三维材质、品牌主张与渠道资料深度。

## 主线

1. 首屏：联野为 AI 新品对接渠道、组织体验，把购买意向带回品牌。
2. 场景：三条销售路径，每条用一个具体产品例子说明任务、体验、品牌跟进。合作形式、买家问题与经营者名称随路径变化。
3. 职责：联野稳定展示三项工作，品牌准备材料与成交履约职责可同时看清。
4. 联系：真实邮件、沟通提纲与经营者合作入口；FAQ 由访客主动展开。

## 合并与删除

- intro 的重复价值宣言并入首屏服务定义。
- products 的第二轮产品分类并入路径中的例子。
- 五种合作形式不再作为独立按钮组，与路径一起解释。
- 路径过程变为非交互进度，保留动态暂停。
- 完整目录按需展开；默认展示相关经营者名称，不强迫主线读者穿过数据库。
- 六步自动合作纸张与重复交付说明合并为稳定的职责展示。
- 独立双边口号屏合并到联系区。
