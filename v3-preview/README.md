这是独立重做的预览，没有覆盖生产或旧版本。240条公开参考、26个二级经营分类；三条销售路径、三类示意产品；首屏与模块默认运行的动态。人物插画是静态，产品、问题、软件界面与合作事件自动演示，均可暂停。

在仓库根目录启动：

```sh
python3 -m http.server 8823 --bind 127.0.0.1 --directory v3-preview
```

- assets/：六幅新原创素材、品牌标识与真实合作提纲。
- data/：具名市场资料、来源检查与迁移记录。
- design/：两方向与状态构图、手机构图、提示词、数据及媒体处理脚本。
- docs/：Clay模块映射、设计规范、叙事、资料边界与QA说明。
- qa/：桌面/手机全站与状态截图、四段真实录屏和首屏动图、执行结果。
- reference/：仅用于本机研究的Clay官方媒体索引，不参与联野产品页面。媒体直接来自官方地址；未复刻原站完整运行。
