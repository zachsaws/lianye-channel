# 联野 V3｜设计规范与叙事

视觉语言：奶油白的新品街区、原创实体产品、具体经营场景、朱红的推进方向。大图负责解释场景，短句负责说明动作，资料密度放进可继续探索的图谱。移除上一版倾斜资料页与旅行眼镜设定。

## 叙事

1. 好产品，不该输在渠道上。创新产品应走到真实买家面前。
2. 门店让人上手，内容让人看到实测，社群让共同需求的人一起试。销售路径与预约、快闪、实测、试用等合作形式分层。
3. 240个公开参考、26个二级经营分类。每个入口可展开业务、地区线索、可讨论的方向、仍需确认事项和来源。
4. 产品选择从购买前的疑问出发：陪伴设备需要实际互动，AI创作软件需要进入真实工作流，创作硬件需要看原始效果。它们不是客户案例，也不是品类专属路径。
5. 联野把产品事实、合作材料、伙伴安排、体验、品牌承接与复盘推进清楚；品牌原则上直接成交和履约。
6. 品牌与伙伴各自有价值、责任和真实联系入口。

## 字体与色彩

- 系统中文字体；不下载外部字体。标题用600字重，主要场景标题500。
- 桌面主标题约79px，模块标题最多65px；手机主标题42px、模块标题34px，场景主句23–30px。
- 正文桌面14–17px、手机12–14px。资料索引与来源是次级层次；展开的手机资料正文12px。
- 主墨色#252e29，正文辅助#5a655c，纸色#fdfbf6，奶油白#f7f1e8，朱红#bf432f，深绿#24443b，浅绿#e5eacb。
- 选中状态同时使用文字、下划线、aria-pressed，避免仅依赖颜色。蓝色焦点轮廓保留。

## 动作规范

- 首屏18秒循环，不需要点击播放。样机沿三条路线进入门店、内容和社群，出现对应的具体问题。
- 三条销售路径各有独立场景与三个阶段，进入视口后自动演示。选择某阶段或合作形式后暂停该模块；可继续。
- 三类产品各有三个动作。默认依次演示，用户选择某类产品后锁定该类，仅继续它内部的三个动作。
- 合作过程六步，每步约4.5秒。产品在角色之间移动，购买意愿回到品牌，最后说明复盘选择；没有订单、成交率或AI生成结果。
- 所有模块可暂停；系统降低动态偏好下默认停播，可由用户明确开启本页动态。离开视口停止模块时钟和CSS动画。
- 手机重新组织上下关系，不缩放整张桌面图。二级分类栏与步骤栏只在自身区域横向滚动；主体页面不横向溢出。

## 素材与构图

6个新素材均用内置图像生成工具创作：街区、门店、内容工作室、社群空间、透明陪伴设备、透明创作相机。项目素材在assets/；最终提示词集合在design/image-prompts.md。软件示意界面、产品路线与合作动作是项目原生代码。

构图稿包含两个方向、三条路径与三类产品，以及手机重排。采用“可运行的新品街区”，编辑式图册的排版用于二级资料。构图稿用于本轮实现比对；实际浏览器中调整了手机软件区高度、分类栏宽度与合作产品位置。没有把AI自审或截图数量当成用户审美接受。
