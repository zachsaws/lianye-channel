# 资料范围与产品选择

## 为什么移除眼镜单一案例

此前“想记录沿途，不想总举手机”过窄，又是未经验证的产品设定。让它贯穿全站，会把联野的适用范围误读成智能眼镜渠道服务；资料页的形式也没有展示购买判断。

本轮用三种不同的购买不确定性组织演示：

- 陪伴设备：实际互动体验、响应限制与日常维护。
- AI创作软件：是否能进入用户自己的任务、素材与工作流，以及付费和使用条件。
- 创作硬件：原始效果、测试情境、适用条件与限制。

所有产品无品牌，都是情境示意。没有把选定路径写成唯一答案，也没有虚构实际产品性能。

## 图谱范围

最终240条公开市场参考，26个二级经营分类。按当前编辑主分类，零售与体验136、内容24、社群19、企业与生态61；这些数字是资料入口数量，不是独立采购主体、客户、合作伙伴或可调用网络规模。

保留上一版113个记录ID；从既有研究拓展信息，并对33个新增官方站点作可达性和内容身份核查，30个进入参考。36氪本次未取到可确认内容、嘉立创开源平台返回418，未因此判断它们不存在；PMCAFF官方显示服务已停止，未展示为有效入口。未通过项保存在source-checks.json与migration.json。

简称与全称用ID和别名合并，包括E宠/重庆易宠、东莞博思、沈阳恒宇和禹亮科技的全称。少数派与其会员社区等入口保留母体关系，不能加总为独立经营组织。

每条资料包含经营描述、产品方向、二级分类、地区线索、来源、资料日期与证据局限。历史记录没有被伪装成本次逐条实时核验；本次新增官网的身份核查，也不证明它可以提供商单、私域触达或产品销售。
