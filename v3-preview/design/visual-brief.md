# 重新设计的三项约束

视觉主张：像可探索的新品街区与行业图谱，画面用实体产品、真实经营场景和可见动作推进；排版以大标题、短句与开放布局组织，摆脱倾斜文档和工作台式卡片。

内容结构：品牌承诺 → 三条真实销售路径与深入图谱 → 三种购买不确定性的产品示意 → 一次合作的推进与责任 → 品牌和伙伴双边价值 → 真实联系。

动态主张：首屏默认有产品沿街区移动与问题事件；路径进入视口自动演示（可暂停），阶段、产品、话语与承接同步；三类产品各有不同的动态构图，合作画面在滚动进入后逐步运行。降低动态偏好下默认停播，并提供清楚的状态。

两方向比较：A，编辑式行业图册，优点是资料密度高，缺点是首页仍容易像研究报告；B，可运行的新品街区，主视觉与场景承担解释，图谱提供纵深。选择B，将A保留在二级资料的排版中。

产品选择从买家疑问出发：陪伴设备要实际互动；AI创作软件要进入自己的工作流程；创作硬件要看实测与原始效果。这些是场景假设，不是实际客户案例，也不代表每类产品仅能走一种路径。
