# V2.2 场景与连续合作画面

视觉主张：保留奶油白与原创新品街区，将大幅实体场景、朱红连接线和有去处的产品对象作为统一语言。

内容顺序：品牌承诺 → 三条销售路径的三幕演示与公开通路 → 同一款产品的六步合作 → 双边价值 → 真实联系入口。

交互主张：路径选择同时更新主图、工作物、合作形式与具名参考；三幕中样机进入场景，买家问题出现，再交由品牌；合作六步始终保留眼镜、产品资料和品牌承接位置，分层移动与展开，不清空整屏。

独立手机构图：路径大图居上、操作与当前工作物居下；合作画面由桌面左右流转改为上下流转，保留产品与资料联系，每步一个主句。

边界：场景及眼镜均为原创示意；资料为预设演示，不调用真实AI；具名通路为公开市场参考，非合作背书；成交与履约由品牌原则上承接，观察数据等待真实合作。
