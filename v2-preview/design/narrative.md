# 联野 V2 叙事概要

## 给访客的一句话
好产品，不该输在渠道上。联野为 AI 时代创新产品探索分布式新品起销网络，让产品从 Demo 走向真实需求、首次销售与后续增长判断。

## 每屏只承担一件事
| 位置 | 主张 | 访客能得到什么 |
| --- | --- | --- |
| 首屏 | 好产品，不该输在渠道上 | 联野关注创新产品走向市场，入口为探索具体起销场景 |
| 起销网络 | 更要走到会买的人面前 | 切换创作者、社群、场景经营者、体验节点，理解需求、合作起点和品牌成交路径 |
| 双边价值 | 产品找到买家，伙伴获得新生意 | 品牌保留成交与履约，伙伴用自己的受众与场景创造价值，联野推进具体合作 |
| 首次合作 | 先跑通一个场景，再决定下一步 | 四步具体工作与首次交付、费用、承诺范围，Demo先体验而非假定能开卖 |
| AI辅助 | 让准备更轻，让生意更近 | 资料整理与建议由AI辅助，人确认事实并推动经营，未来复用需要授权与验证 |
| 联系 | 下一款好产品，一起带到真实生活里 | 已核对邮箱、按品牌/伙伴准备邮件内容、可复制沟通提纲，无假提交 |

## 业务边界
近期合作是明确范围的小项目，联野通过实际服务与经确认的新增价值收费。品牌原则上直接承接订单、供货、退款和售后，不建立多级经销体系。服务费与增量贡献的计费、归因和结算需启动前约定。

## 现阶段与长期愿景
当前为首批合作验证阶段。场景建筑与人物为原创示意，不代表签约伙伴或实际案例。网络不是已可调用的渠道池，不展示未经验证规模、成交、收益与AI指标。长期方向是在真实项目和明确授权基础上，让经验帮助后续新品；网络复用、AI成本增量、付费意愿、单位经济与可复制增长都尚待验证。

## 历史材料如何使用
