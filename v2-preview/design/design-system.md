# 联野 V2 设计规范

## 核心语言
“新品街区”：用一条朱红路径，把产品、内容、社群与体验连接起来。原创建筑模型是全站的具象锚点；后续通过路径、对开版面、线性步骤和纸张延续材料感。避免泛化科技球体、仪表盘、logo墙和模板卡片。

## 色彩
| 用途 | 色值 |
| --- | --- |
| 主文字 | #242b28 |
| 辅助文字 | #58625c |
| 象牙首屏 | #f8f1e8 |
| 内容纸白 | #fdfbf6 |
| 路径与大号数字 | #e34e32 |
| 浅色文字所在的朱红底 | #c7442d |
| 深色朱红文字 | #ae321f |
| 双边价值浅绿 | #e5eacb |
| AI 辅助深绿 | #243f38 |

朱红路径与插画中的钴蓝、奶黄、鼠尾草作为语义色：区分不同真实场景，不承担数据编码。小字浅色/朱红底对比已加深：#fff8ed / #c7442d 约 4.64:1，白色按钮文字约 4.89:1；不能再把小字底色改回 #e34e32。

## 字体与层级
- 仅使用系统无衬线，中文优先 PingFang SC / Microsoft YaHei，无外部字体请求。
- 桌面1440：首屏约80.6px；章节60.5px；场景标题43.2px；正文16–21px；说明11–14px。
- 手机390：首屏约46px，三行独立构图；章节34px，行高1.5；正文15–17px；补充说明10–13px。
- 大标题字距略紧，正文不压缩。长内容通过渐进展开组织，而不是缩小字体。

## 版式
桌面页面横向铺满，内层左右边距约64px。首屏上方标题与短引导，下面大面积场景；核心章节采用图片与内容对照；双边价值为对开；合作流程为四列；AI采用深绿整屏与两张具象纸张；联系以朱红收束。

手机边距24px：导航折叠；首屏标题三行；四个场景入口按2×2操作区排列，图像单独聚焦、说明在下方；双边价值上下展开；四步流程改为纵向编号；联系标题三行。所有内容有真实 DOM 文字，不以图片承载网页文案。

## 动作
- 入场：标题上移淡入0.85秒，场景轻微缩放1.5秒。
- 滚动：章节进入后淡入0.7秒，路径线进入后展开1.1秒，触发一次。
- 操作：场景图片聚焦转场0.75秒；链接箭头微移；FAQ原生展开；菜单状态同步ARIA。
- prefers-reduced-motion 下取消动画、过渡与平滑滚动，所有内容直接可见。

## 交互与无障碍
场景为原生button+aria-pressed，唯一选中，支持方向键与Home/End；说明区域aria-live。导航、main、章节标题为语义结构；跳转链接、焦点轮廓、图片替代文字均保留。手机导航支持Escape与选择后关闭。FAQ使用原生details/summary。没有后端提交；邮件只准备内容，复制仅写入本机剪贴板。关闭脚本时保留正文、导航、FAQ、邮件，追加全部入口文字。

## 素材
A图与B图均为内置image_gen原创生成；完整提示词见 image-prompts.md。A图优化后桌面约296KiB、手机约84KiB。源图和故事板只用于设计审阅，不随首页加载。

## 视觉还原原则
故事板是事前设计资产，真实截图是事后验证。按“结构、颜色、标题比例、场景裁切、信息顺序、手机重新排版”对照；不以源文件存在或页面返回200替代视觉检查。后续增添FAQ与更具体的四种入口，使实际页面高度高于最初故事板；此差异保留在QA报告中。
